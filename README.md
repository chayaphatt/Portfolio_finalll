# Portfolio_1002

เว็บไซต์พอร์ตโฟลิโอส่วนตัวและหน้ารวมผลงานการบ้านรายวิชา ผลงานชิ้นนี้พัฒนาขึ้นในช่วงการศึกษาระดับชั้นปีที่ 3 


## About The Project

เว็บไซต์นี้สร้างขึ้นเพื่อนำเสนอข้อมูลส่วนตัว ทักษะความสามารถ ช่องทางการติดต่อ และรวบรวมแบบฝึกหัด/ผลงานการบ้านประจำสัปดาห์ ที่ได้เรียนรู้ตลอดทั้งภาคการศึกษา โดยเน้นการออกแบบสไตล์ Minimal Pastel โทนสีชมพู พร้อมลูกเล่น Interactive และ Responsive Design ที่รองรับการแสดงผลทุกหน้าจอ

### Tech Stack
* **HTML5:** โครงสร้างหน้าเว็บและ Semantic Tags
* **CSS3:** จัดเลย์เอาต์ด้วย Flexbox, ใส่เงา Soft Shadows, Gradient Glow และ Hover Animations
* **JavaScript:** การทำงานโต้ตอบพื้นฐานและการเปลี่ยนหน้า
* **Font Awesome:** ไอคอนประกอบส่วนต่างๆ
* **Google Fonts:** ฟอนต์ Poppins
